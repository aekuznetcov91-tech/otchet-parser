# Папка для загрузки исходных файлов (Raw Data)

Поместите сюда ваши ежедневные файлы:
1. **Файл сделок:** любая выгрузка сделок (Excel / CSV / XLS / XLSM) — парсер сам найдет колонки "Стадия сделки", "Предполагаемая дата закрытия", "Товар" и др.
2. **Файл лидов:** любая выгрузка лидов из CRM/BI — парсер найдет "event_name", "client_id", "BI / Партнер".
3. **Справочник партнеров:** Excel с колонками "Битрикс", "BI", "КАМ", "Почта".
4. **Скриншот / Метрики витрины:** изображение воронки (`funnel.jpg` / `funnel.png`) или файл `funnel_metrics.json`.

---
*При загрузке файлов через GitHub сайт и дашборд обновляются автоматически.*
