Контекст:
Я хочу полностью переписать старый Excel VBA-макрос на Vanilla JavaScript.
Макрос занимался ETL: брал 3 сырые Excel-выгрузки (Сделки, Лиды, Справочник партнеров), агрегировал их и формировал файл data.json.
У меня уже написан фронтенд (index.html), который визуализирует этот JSON. Мне нужен только скрипт парсера с использованием библиотеки SheetJS (xlsx.full.min.js), который будет принимать файлы через Drag-and-Drop и на выходе генерировать структуру, строго соответствующую моему эталонному JSON.

Эталонная структура выходного JSON:
Скрипт должен сформировать объект с двумя массивами: {"sys_db": [...], "sys_db_partners": [...]}
Пример объекта для sys_db:

Ключевые правила трансформации данных (Data Mapping Rules):
Напиши логику обработки массивов, соблюдая следующие строгие правила:

Нормализация брендов: Столбец ТОВАР содержит марку и модель. Скрипт должен уметь правильно классифицировать бренды. Важно: модели Dashing и X70 Plus должны жестко мапиться и определяться как бренд JETOUR.

Форматирование дат: При любой конвертации дат из сырых таблиц в строки (если это потребуется) строго используй порядок день-месяц-год (DD.MM.YYYY). В JSON для полей дат (DealDate, PrepayDate) сохраняй Excel Serial Number, как в эталоне.

Обработка VIN: Парсер должен собирать VIN-номера. Если в сырой выгрузке попадается VIN короче 17 символов, система не должна его отбрасывать — обязательно записывай эту короткую последовательность в JSON (фронтенд сам подсветит ее красным как ошибку).

Расчет Выручки (Revenue): Для сделок в статусе "ЗАКРЫТО И РЕАЛИЗОВАН" (если товар не "КРЕДИТ", "КАСКО", "ОСАГО", "ВНЕСЕНИЕ АВАНСА", "ГАП СБЕР") нужно считать чистую выручку очищенную от НДС по формуле: Комиссия / 1.22. Округлять до 2 знаков.

ChartGroup Logic: Если тип B2C равен "МП1", "МП2", "МП3" или "ВХОДЯЩАЯЗАЯВКА" — присваивать ChartGroup: "Partners". В остальных случаях — "Новые авто".

Задача:
Напиши один самодостаточный HTML-файл (MVP-версию).
В нем должна быть простая зона Drag-and-Drop для файлов, логика чтения через SheetJS, описанная выше бизнес-логика трансформации (mapping/reducing) и кнопка «Скачать data.json». Код должен быть чистым, с комментариями и без использования фреймворков. Сделки связываются с SeniorManager из Справочника КАМов.
