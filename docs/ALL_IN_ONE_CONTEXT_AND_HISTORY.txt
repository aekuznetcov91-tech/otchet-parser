1. АРХИТЕКТУРА СИСТЕМЫ И ИСТОЧНИКИ ДАННЫХ
--------------------------------------------------------------------------------
Система объединяет 4 ключевых слоя:

А) Единая папка сырых данных (`raw_data/`):
- Содержит входящие файлы сделок, лидов, справочников и скриншотов воронки.
- Файлы могут иметь произвольные имена: движок автоматически определяет назначение по набору столбцов.

Б) Автономный серверный и локальный парсер (`scripts/parser_engine.py`):
- Потоковое чтение XML для сверхбыстрой обработки файлов любого объема (включая лиды на 150 000+ строк).
- Умный поиск шапок таблиц со смещением.
- Автоматическая очистка выручки от НДС (`comm / 1.22`).
- Отсечение дублирующих фин. продуктов (Кредит Сбер, ФинКАСКО, КАСКО Плюс).
- Подсчет физических выданных автомобилей.
- Динамический расчет сквозной воронки 6 брендов (JETOUR, LADA, TENET, CHANGAN, GAC, SOLARIS).
- Формирование `site/data.json`.

В) Интерактивный SPA-дашборд (`site/index.html`):
- Хостинг: Cloudflare Pages (https://dashbord-partners1.pages.dev)
- Прокси/Воркер: https://dashbord-partners.beckelaguas723.workers.dev (Логин: `director`, Пароль: `password`)
- Стек: Tailwind CSS, Chart.js, Lucide Icons, Chartjs Plugin Datalabels.
- Табы: 
  1. Диаграмма (KPI, графики, сплиты Китай/LADA)
  2. Динамика
  3. Динамика месяцы
  4. Партнеры (КАМы, дилеры)
  5. Менеджеры
  6. 🎯 Воронка брендов (Сводная матрица 6 брендов, расчеты, офферы, развилка ДЦ / ФДЦ, сплиты лидов и выручки без МП2)
  7. В ожидании

Г) Автоматический деплой и облачный пайплайн:
- Локально в 1 клик: `Выгрузить_на_Сайт.bat`
- В облаке: `.github/workflows/auto_parse_and_deploy.yml` на серверах GitHub Actions.

--------------------------------------------------------------------------------
2. СТРУКТУРА JSON (`data.json`)
--------------------------------------------------------------------------------
Объект содержит:
- `sys_db`: массив всех сделок, авансов и ожиданий.
- `sys_db_partners`: массив операций в партнерском разрезе (с привязкой КАМ).
- `funnel_metrics`: кликстрим витрины PostHog.
- `brand_funnel`: структура сквозной воронки по 6 брендам (JETOUR, LADA, TENET, CHANGAN, GAC, SOLARIS).

--------------------------------------------------------------------------------
3. МАТЕМАТИКА И ПРАВИЛА РАСЧЕТА KPI
--------------------------------------------------------------------------------
1. Количество сделок = sum(SaleQty) по записям с SaleQty == 1 (реальные автомобили, без доп. продуктов).
2. Количество авансов = sum(PrepayQty) по записям с PrepayQty == 1.
3. Тотал Выручка = sum(Revenue) по всем закрытым сделкам (SaleQty == 1, сумма комиссии / 1.22).
4. Сплит выручки:
   - Выручка LADA = sum(Revenue) где Brand == 'LADA'.
   - Выручка Китай = sum(Revenue) где Brand != 'LADA'.
5. ARPU (Выручка на 1 сделку) = Тотал Выручка / Количество сделок.
6. Воронка брендов:
   - Расчет конверсий ведется без учета МП2.
   - Квалификация: целевые лиды (`Целевой == 1`).
   - Развилка: Ветка ДЦ (передача лида) vs Ветка ФДЦ (онлайн-заявки и одобрения).
