2. СТРУКТУРА JSON (`data.json`)
--------------------------------------------------------------------------------
Объект содержит 2 ключевых массива: `sys_db` (все операции) и `sys_db_partners` (партнерский срез).

Ключевые поля в `sys_db`:
- `VIN` (string): Идентификатор авто или номер внесения аванса (при длине < 17 фронтенд подсвечивает ошибку).
- `SaleQty` (int: 0 или 1): Флаг закрытой сделки (1 = состоялась выдача/реализация).
- `PrepayQty` (int: 0 или 1): Флаг внесенного аванса/предоплаты (1 = аванс внесен).
- `WaitQty` (int: 0 или 1): Флаг автомобиля в статусе ожидания выдачи.
- `Price` (float): Стоимость автомобиля в рублях (без НДС).
- `Revenue` (float): Чистая выручка компании со сделки (без НДС: сумма / 1.2).
- `Comm` (float): Комиссия.
- `Brand` (string): Бренд автомобиля (LADA, CHERY, HAVAL, GEELY, GAC, CHANGAN, JETOUR, TANK, EXEED, JACOO, OMODA, BELGEE и др. Для авансов: «ВНЕСЕНИЕ»).
- `B2C` (string): Канал продаж / тип сделки (ФДЦ, Передача лида, Online, МП, МП1, МП2, МП3, Директ и т.д.).
- `Manager` (string): Ответственный менеджер (например, «Фокин Борис»).
- `SeniorManager` (string): Старший менеджер / куратор (например, «Гамаюнов Вячеслав»).
- `SaleMonth` / `PrepayMonth` (string): Месяц в формате "YYYY-MM" (например, "2026-08").
- `DealDate` / `PrepayDate` (int/float): Дата в формате Excel Serial Number.
  *Конвертация:* Календарная дата = 1970-01-01 + (Serial - 25569) дней.

--------------------------------------------------------------------------------
3. МАТЕМАТИКА И ПРАВИЛА РАСЧЕТА KPI
--------------------------------------------------------------------------------
1. Количество сделок = sum(SaleQty) по записям с SaleQty > 0.
2. Количество авансов = sum(PrepayQty) по записям с PrepayQty > 0.
3. Тотал Выручка = sum(Revenue) по всем закрытым сделкам (SaleQty > 0).
4. Сплит выручки:
   - Выручка LADA = sum(Revenue) где Brand == 'LADA' и SaleQty > 0.
   - Выручка Китай = sum(Revenue) где Brand != 'LADA' и SaleQty > 0.
5. ARPU (Выручка на 1 сделку) = Тотал Выручка / Количество сделок.
6. Средний чек авто = sum(Price) / Количество сделок.

Создание аналогичного дашборда строится по модульному принципу **«Zero Backend»** (без серверов, баз данных и Node.js). Вся система состоит из 3 компонентов: **Парсер Excel** ➔ **Файл данных `data.json`** ➔ **SPA-Дашборд на Cloudflare**.

---

### Архитектурная схема:

```
[ Сырые Excel-отчеты (1С / CRM / Сделки) ]
                   │
                   ▼  (Drag & Drop в браузере)
┌──────────────────────────────────────────────┐
│        1. ЛОКАЛЬНЫЙ ПАРСЕР (parser.html)      │
│  - Читает Excel через SheetJS                │
│  - Очищает суммы, сопоставляет по ключам      │
│  - Считает KPI и генерирует data.json        │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
               [ data.json ]
                       │
                       ▼  (Деплой папки site/ на Cloudflare)
┌──────────────────────────────────────────────┐
│        2. ЖИВОЙ ДАШБОРД (site/index.html)     │
│  - Tailwind CSS (адаптивная верстка)         │
│  - Chart.js (графики, динамика, сплиты)      │
│  - Кнопки копирования в Excel (TSV) и PPT    │
└──────────────────────────────────────────────┘
```

---

### Пошаговый план создания:

#### Шаг 1. Определить структуру и метрики
1. **Исходные данные:** какие таблицы загружаются (например, «Продажи.xlsx» и «Авансы.xlsx»).
2. **Ключ связи:** по какому полю связывать строки (ID клиента, VIN, номер заказа).
3. **Целевые KPI:** что нужно выводить на карточки (Выручка, Кол-во сделок, Средний чек, ARPU, Конверсия) и какие фильтры нужны (Период, Менеджер, Категория).

---

#### Шаг 2. Создать парсер (`parser.html`)
Парсер — это локальный HTML-файл, который открывается в любом браузере:
* **Библиотека:** `SheetJS` (`xlsx.full.min.js`) — читает Excel прямо на клиенте.
* **Функционал:**
  1. Зона Drag-and-Drop для файлов.
  2. Нормализация данных (деление на НДС `1.2`, очистка пробелов, форматирование дат).
  3. Сохранение файла `data.json` на диск (через `showSaveFilePicker` или обычное скачивание).

---

#### Шаг 3. Собрать фронтенд дашборда (`site/index.html`)
Фронтенд состоит из одного HTML-файла с подключением библиотек через CDN (без сборщиков типа Webpack/Vite):
* **Tailwind CSS** (`https://cdn.tailwindcss.com`) — сетка, карточки, адаптивность.
* **Chart.js** — круговые диаграммы сплитов и линейные графики динамики.
* **html2canvas** — для кнопки «Скопировать график в PowerPoint» (копирует изображение с прозрачным фоном в буфер).
* **Логика загрузки:** при открытии страницы вызывается `fetch('data.json?v=' + Date.now())`, данные парсятся и наполняют DOM.
* **Таблицы:** генерируют TSV-текст для мгновенной вставки в Excel по кнопке «Скопировать таблицу».

---

#### Шаг 4. Развернуть на Cloudflare Pages (бесплатно)
1. Зарегистрироваться на [cloudflare.com](https://dash.cloudflare.com).
2. Перейти в **Workers & Pages** ➔ **Create application** ➔ **Pages**.
3. **Варианты деплоя:**
   * *Через веб-интерфейс:* просто перетащить папку `site` (с `index.html` и `data.json`) в окно браузера.
   * *Через терминал:* `npx wrangler pages deploy site --project-name=my-new-dashboard`
4. Получить постоянный URL вида `https://my-new-dashboard.pages.dev`.
5. *(Опционально)* Закрыть дашборд паролем или входом по рабочей почте через **Cloudflare Zero Trust** (вкладка Access Policies).

---

### Как мы можем сделать это сейчас:
Если у вас есть задача запустить новый дашборд (под другое направление, отдел или проект):
1. **Прикрепите примеры Excel-файлов** (или опишите, какие столбцы в них содержатся).
2. **Назовите ключевые KPI и срезы**, которые хотите видеть.
