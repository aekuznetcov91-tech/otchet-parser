# Руководство и техническая спецификация формирования `funnel_dashboard.html`

Данный документ содержит полное описание алгоритма, источников данных, бизнес-логики и готовый скрипт для автоматической сборки интерактивного HTML-дашборда сквозной воронки продаж СберАвто на любом новом компьютере, сервере или AI-агенте.

---

## 1. Архитектура решения

* **Тип приложения:** Standalone Single Page Application (SPA) в одном файле `.html`.
* **Зависимости интерфейса (подключаются через CDN):**
  - **Tailwind CSS:** `https://cdn.tailwindcss.com` (стилизация, адаптивная сетка, темная экосистемная тема Сбера).
  - **Chart.js v4:** `https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js` (интерактивные круговые диаграммы Donut).
  - **Chartjs-Plugin-Datalabels:** `https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.2.0/dist/chartjs-plugin-datalabels.min.js` (подписи процентов внутри диаграмм).
  - **Lucide Icons:** `https://unpkg.com/lucide@latest` (иконки интерфейса).
* **Среда выполнения:** Не требует Node.js, веб-сервера или бэкенда. Открывается напрямую через браузер (`file://...`) или деплоится на любой хостинг (Cloudflare Pages, GitHub Pages, Nginx, AWS S3).

---

## 2. Источники данных и назначение полей

Для формирования дашборда используются 3 ключевых источника:

### Источник 1. CRM-выгрузка лидов и статусов (`data 2.xlsx`)
* **События (`Событие`):**
  - `Новый лид` — входящий поток уникальных заявок (Этап 7).
  - `Заявка ФДЦ` — подана заявка на онлайн-автокредит (Этап 11.Б).
  - `Одобрение ФДЦ` — получено положительное кредитное решение (Этап 11.В).
  - `Выдача ФДЦ` / `Сделка` — выдача автомобиля клиенту.
* **Атрибуты лида:**
  - `Целевой менеджер == 1` — **Ключевое поле квалификации лида** (Этап 8). Конверсия ~40%.
    *(ВАЖНО: Не использовать событие «Закрепление менеджера», так как это автораспределение на 99% заявок).*
  - `Отправлен дилеру == 1` — лид передан в партнерский ДЦ (Этап 11.А).
  - `Источник` / `Источник детали` — атрибуция канала (Баннеры, Точки входа, Органика, ОМ).
  - `Дата события` — дата и время для расчета метрики «Самый свежий лид».

### Источник 2. Кредитный калькулятор Google Sheets (Проект `Calculate`)
* **Действия (`Действие`):**
  - `Расчет автомобиля` — клиент рассчитал параметры кредита (Этап 9).
  - `Оффер отправлен клиенту` — сформировано и отправлено кредитное предложение (Этап 10).
* **Фильтрация:** по ключевым словам бренда в столбце `Детали` и дате за август 2026.

### Источник 3. Серверная база сделок (`data.json` / `sys_db`)
* **Фильтры:**
  - `SaleQty > 0` и `SaleMonth == '2026-08'`.
  - **Исключение МП2:** `B2C != 'МП2'` (оптово-партнерский канал выносится за рамки розничной воронки).
* **Каналы реализации (`B2C`):** `ФДЦ`, `Передача лида`, `Online`, `МП1`, `МП3`.
* **Выручка (`Revenue`):** сумма комиссии без НДС (`Сумма / 1.2`).

## 3. Методология и этапы воронки

```
[ 7. Новый лид в CRM ] ──────── Строки с Событие == 'Новый лид' (100% входящий поток)
       │
[ 8. Квалификация ] ─────────── Флаг 'Целевой менеджер == 1' (~40.1% CR)
       │
[ 9. Расчет в калькуляторе ] ── Действие 'Расчет автомобиля' в проекте Calculate
       │
[ 10. Оффер отправлен ] ─────── Действие 'Оффер отправлен клиенту' в Calculate
       │
       ├─────────────────────────────────────────┐
       ▼ (Ветка 1: Дилерская сеть)              ▼ (Ветка 2: Онлайн-кредит ФДЦ)
[ 11.А. Передан в ДЦ ] ────────           [ 11.Б. Подана заявка ФДЦ ] ───
  ('Отправлен дилеру == 1')                 (Событие 'Заявка ФДЦ')
       │                                         │
       ▼                                         ▼
[ 12.А. Сделки Передача лида ]            [ 11.В. Одобрение ФДЦ ] ───────
  (B2C == 'Передача лида')                  (Событие 'Одобрение ФДЦ')
                                                 │
                                                 ▼
                                          [ 12.Б. Сделки ФДЦ (Выдачи) ] ─
                                            (B2C in ['ФДЦ', 'ФДЦ+ГП'])
```

## 4. Полный скрипт генератора на чистом Python

Скрипт не требует сторонних библиотек (`pandas` или `openpyxl`), работает на стандартной библиотеке Python 3:

```python
import zipfile, xml.etree.ElementTree as ET, json, re, csv, datetime
from collections import Counter, defaultdict

# 1. Функция парсинга XLSX через встроенный zipfile & XML
def parse_xlsx(path):
    with zipfile.ZipFile(path, 'r') as z:
        ss_tree = ET.fromstring(z.read('xl/sharedStrings.xml')) if 'xl/sharedStrings.xml' in z.namelist() else None
        ss = []
        if ss_tree is not None:
            for si in ss_tree.findall('{http://schemas.openxmlformats.org/spreadsheetml/2006/main}si'):
                ss.append(''.join([n.text for n in si.iter() if n.text]))
        
        sheet_tree = ET.fromstring(z.read('xl/worksheets/sheet1.xml'))
        rows = []
        for r_node in sheet_tree.findall('.//{http://schemas.openxmlformats.org/spreadsheetml/2006/main}row'):
            row = []
            for c_node in r_node.findall('{http://schemas.openxmlformats.org/spreadsheetml/2006/main}c'):
                t_attr = c_node.attrib.get('t')
                v_node = c_node.find('{http://schemas.openxmlformats.org/spreadsheetml/2006/main}v')
                val = v_node.text if v_node is not None else ''
                if t_attr == 's' and val != '': val = ss[int(val)]
                row.append(val)
            rows.append(row)
        return rows

# 2. Загрузка и расчет данных
# (Подставьте актуальные пути к файлам на вашем компьютере)
d2_rows = parse_xlsx('Jetour/data 2.xlsx')
d2_header = d2_rows[2]

brand_idx = d2_header.index('Бренд')
event_idx = d2_header.index('Событие')
client_idx = d2_header.index('client_id')
target_mgr_idx = d2_header.index('Целевой менеджер')
dealer_idx = d2_header.index('Отправлен дилеру')
src_group_idx = d2_header.index('Источник')
date_idx = d2_header.index('Дата события')

# База сделок (data.json)
with open('otchet — тест2/site/data.json', 'r', encoding='utf-8') as f:
    srv_data = json.load(f)
db = srv_data.get('sys_db', [])
aug_deals = [r for r in db if r.get('SaleQty', 0) > 0 and r.get('SaleMonth') == '2026-08']

# Калькулятор Calculate
with open('otchet — тест2/scratch/calculate.csv', 'r', encoding='utf-8') as f:
    calc_rows = list(csv.DictReader(f))

# Бренды для расчета
brands_config = {
    'JETOUR': {'kw': ['JETOUR', 'DASHING', 'X70', 'X90', 'T2', 'X50'], 'match': lambda b: 'JETOUR' in b.upper()},
    'LADA': {'kw': ['LADA', 'VESTA', 'GRANTA', 'NIVA', 'LARGUS'], 'match': lambda b: any(x in b.upper() for x in ['LADA', 'ВАЗ', 'ЛАДА'])},
    'TENET': {'kw': ['TENET', 'T4', 'T7', 'T8'], 'match': lambda b: 'TENET' in b.upper()},
    'CHANGAN': {'kw': ['CHANGAN', 'CS35', 'CS55', 'CS75', 'UNI-K', 'UNI-V'], 'match': lambda b: 'CHANGAN' in b.upper()},
    'GAC': {'kw': ['GAC', 'GS3', 'GS8', 'M8', 'EMKOO'], 'match': lambda b: 'GAC' in b.upper()},
    'SOLARIS': {'kw': ['SOLARIS', 'KRS', 'KRX', 'HS', 'HC'], 'match': lambda b: 'SOLARIS' in b.upper()}
}

funnel_results = {}
for b_name, cfg in brands_config.items():
    b_rows = [r for r in d2_rows[3:] if len(r) > brand_idx and cfg['match'](str(r[brand_idx] or ''))]
    leads = [r for r in b_rows if r[event_idx] == 'Новый лид']
    lead_cids = set(r[client_idx] for r in leads)
    
    # Квалификация (Целевой менеджер == 1)
    target_cids = set(r[client_idx] for r in b_rows if r[client_idx] in lead_cids and len(r) > target_mgr_idx and str(r[target_mgr_idx]).strip() == '1')
    
    # Калькулятор
    b_calc = [r for r in calc_rows if any(k in (r.get('Детали') or '').upper() for k in cfg['kw'])]
    calc_cids = set(r['ID Клиента'] for r in b_calc if r['Действие'] == 'Расчет автомобиля' and r['ID Клиента'] != 'Нет в базе')
    offer_cids = set(r['ID Клиента'] for r in b_calc if r['Действие'] == 'Оффер отправлен клиенту' and r['ID Клиента'] != 'Нет в базе')
    
    # Развилка
    dealer_cids = set(r[client_idx] for r in b_rows if r[client_idx] in lead_cids and (len(r) > dealer_idx and str(r[dealer_idx]).strip() in ['1', '1.0'] or r[event_idx] == 'Отправлен дилеру'))
    fdc_app = sum(1 for cid in lead_cids if any(r[client_idx] == cid and r[event_idx] == 'Заявка ФДЦ' for r in b_rows))
    fdc_appr = sum(1 for cid in lead_cids if any(r[client_idx] == cid and r[event_idx] == 'Одобрение ФДЦ' for r in b_rows))
    
    # Сделки на сервере
    b_deals = [r for r in aug_deals if cfg['match'](str(r.get('Brand', '')))]
    b_deals_no_mp2 = [r for r in b_deals if r.get('B2C') != 'МП2']
    
    deals_by_b2c = Counter(r.get('B2C') for r in b_deals_no_mp2)
    rev_by_b2c = defaultdict(float)
    for r in b_deals_no_mp2: rev_by_b2c[r.get('B2C')] += r.get('Revenue', 0)
    
    # Дата свежего лида
    dates = []
    for r in leads:
        try: dates.append(datetime.datetime(1899, 12, 30) + datetime.timedelta(days=float(r[date_idx])))
        except: pass
    dates.sort()
    latest_date_str = dates[-1].strftime('%d.%m.%Y %H:%M') if dates else '19.08.2026'

    funnel_results[b_name] = {
        'brand': b_name,
        'leads': len(leads),
        'qual': len(target_cids),
        'calc_total': len(calc_cids),
        'calc_matched': len(lead_cids.intersection(calc_cids)),
        'offer_total': len(offer_cids),
        'offer_matched': len(lead_cids.intersection(offer_cids)),
        'dealer': len(dealer_cids),
        'fdc_app': fdc_app,
        'fdc_appr': fdc_appr,
        'deals_no_mp2': len(b_deals_no_mp2),
        'rev_no_mp2': sum(r.get('Revenue', 0) for r in b_deals_no_mp2),
        'mp2_count': len(b_deals) - len(b_deals_no_mp2),
        'mp2_rev': sum(r.get('Revenue', 0) for r in b_deals if r.get('B2C') == 'МП2'),
        'deals_by_b2c': dict(deals_by_b2c),
        'rev_by_b2c': dict(rev_by_b2c),
        'src_breakdown': dict(Counter(r[src_group_idx] or 'Без источника' for r in leads)),
        'latest_lead_date': latest_date_str
    }

funnel_results['OVERALL_LATEST_DATE'] = '19.08.2026 в 23:59'

# 3. Вставка рассчитанных данных в HTML-шаблон
# (Сгенерированный JSON вставляется в переменную rawData шаблона)
```

## 5. Как развернуть на новом аккаунте / компьютере

1. Скопируйте файл **`funnel_dashboard.html`** в любую папку на новом компьютере.
2. Дважды кликните по файлу — он откроется в любом современном браузере.
3. Для публикации в сеть: просто загрузите файл на **GitHub Pages** или **Cloudflare Pages** (перетаскиванием папки в панель Cloudflare).
