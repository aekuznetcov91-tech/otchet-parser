# ТЕХНИЧЕСКИЙ КОНТЕКСТ ПРОЕКТА: B2C ANALYTICS DASHBOARD & PARTNERS

**Дата обновления:** 26.08.2026  
**Хостинг/Деплой:** Cloudflare Pages (`dashbord-partners1.pages.dev`), прокси Worker (`dashbord-partners.beckelaguas723.workers.dev`, Basic Auth: `director` / `password`).

## 1. АРХИТЕКТУРА И МОДУЛЬНОСТЬ СИСТЕМЫ

Проект состоит из связанных модулей с единым источником данных `data.json`:

```
site/
├── index.html                    ← Главный SPA-дашборд (7 табов)
├── partner_matcher.html          ← Онлайн-хаб географии брендов (642 ДЦ / 15 брендов / 102 города)
├── scenario_analysis.html        ← Сценарный финансовый анализ vs Бюджет 59.17M ₽
├── parser.html                   ← Локальный Drag-and-Drop парсер отчетов Excel
├── css/
│   └── dashboard.css             ← Стилизация, анимации (shimmer glare, zoom hover, toast)
├── js/
│   ├── utils.js                  ← Форматтеры (fmtNum, fmtRub, fmtPct, fmtMln), Toast-нотификации, clipboard
│   ├── data-loader.js            ← Загрузка data.json, фильтры периодов, План vs Факт Q3 расчеты
│   ├── charts.js                 ← Chart.js Pie/Line графики и таблицы сплита
│   ├── tables.js                 ← Таблицы динамики, партнеров (Master ID + CR), менеджеров, ожидания
│   ├── debtors.js                ← Контроль должников ДКП, группировка, экспорт Excel через SheetJS
│   ├── funnel.js                 ← Сквозная воронка 13 брендов, 6-step PostHog, ДЦ vs ФДЦ, без МП2
│   └── heatmap.js                ← Распределение сделок по регионам РФ
├── data.json                     ← Базовый payload (5386 сделок, 7512 партнеров, 192 должника)
├── partners_registry.json        ← Реестр Master ID партнеров
└── russia_dealer_benchmarks.json ← База дилерских сетей 15 OEM брендов
```

## 2. КЛЮЧЕВЫЕ МОДУЛИ И ФУНКЦИОНАЛ

### А) Главный дашборд (`index.html`) — 7 вкладок:
1. **Диаграмма (`tab-dashboard`):**
   - 5 Top KPI (Сделки, Авансы, Средний чек сплит Китай/Lada, ARPU без НДС, Выручка без НДС).
   - **План vs Факт Q3:** Прогресс-бары к целям Q3 2026 (5 000 авто, 170 млн ₽ выручки, TR% 1.9%).
   - Сплит брендов и сделок B2C (Chart.js Pie + HTML-легенды + кнопка копирования в буфер как PNG).
   - Линейные графики динамики продаж по дням с подсветкой выходных.
   - **Regional Heatmap:** Рейтинг топ-20 регионов РФ по объему продаж и числу ДЦ.
2. **Динамика (`tab-dynamics`):** Оперативная динамика, тип сделки B2C по маркам, структура %.
3. **Динамика месяцы (`tab-dyn-months`):** Понедельное сравнение ARPU/Чека, понедельная B2C динамика.
4. **Партнеры (`tab-partners`):** Сквозной ID, лиды, авансы, сделки с лидов без аванса, сделки с МП, сделки тотал, CR (Сделка/Лид) и кнопка «Править ➔» в Master Matcher.
5. **Менеджеры (`tab-managers`):** Иерархия по старшим менеджерам, сделки и авансы.
6. **Воронка брендов (`tab-funnel`):**
   - Динамические кнопки месяцев (`2026-08`, `2026-07`...) и брендов из `data.json`.
   - 6 шагов воронки витрины PostHog (Listing ➔ Card Show ➔ Card Click ➔ Offer ➔ Click Send ➔ Success).
   - CRM-квалификация и развилка: ДЦ (дилерская сеть) vs ФДЦ (онлайн-кредит).
   - Финансовый итог розницы (строго без учета Опт МП2).
7. **В ожидании (`tab-details`):** Должники ДКП, группировка по компаниям, модальный селектор и мульти-файловая выгрузка индивидуальных `.xlsx` по автохолдингам.

### Б) Онлайн-хаб географии брендов и метчинга (`partner_matcher.html`):
- База 642 крыш дилерских центров в 102 городах РФ по 15 брендам (LADA, Chery, Geely, Haval, Solaris, Changan, Belgee, Jetour, Jaecoo, Omoda, Exeed, Tank, GAC, Москвич, FAW/Hongqi).
- Анализ охвата: подключенные города в СберАвто vs потенциал свободного рынка.
- Редактор Master ID партнеров с маппингом сырых имен из Bitrix и BI.
- Экспорт матрицы в Excel и JSON.

### В) ETL-парсер (`scripts/parser_engine.py`):
- Потоковый парсинг `.xlsx`, `.xlsm` и Bitrix HTML-table `.xls`.
- Дедупликация файлов по MD5.
- Очистка от НДС (`Комиссия / 1.22`), фильтрация доп. продуктов (страхование/кредит).
- Сборка сквозных воронкок 13 брендов и должников ДКП.

## 3. БИЗНЕС-ПРАВИЛА И МЕТРИКИ СБЕРАВТО

- **Бизнес-модель:** Субсидия OEM (скидка на авто) + холдирование 5 000 ₽ + бронь 3 дня + оформление ДКП в ДЦ. Комиссия СберАвто = 2% от ДКП (Выручка без НДС = `Комиссия / 1.22`).
- **Опт МП2 (Wholesale):** Холд 1 000 ₽, клиенты приведены самим дилером под скидку СберАвто. **СТРОГО ИСКЛЮЧЕН** из расчетов розничной воронки.
- **ФДЦ:** Программа онлайн-заведения кредитных заявок Сбера.
- **Цели Q3 2026:** 5 000 авто, 170 млн ₽ выручки, 2.6 млн ₽ средний чек, 1.9% TR%, входящие сделки ≤ 70%.

## 5. ВАЖНЫЕ НЮАНСЫ И ОГРАНИЧЕНИЯ ДЛЯ ИИ
- **НИКАКОГО Node.js в парсере:** Пользователь работает за защищенным корпоративным ПК, установка npm-пакетов для парсера невозможна.
- **Верстка:** Использовать только классы Tailwind. Никаких самописных CSS без крайней необходимости.
- **Верстка графиков для экспорта:** `html2canvas` плохо справляется с обрезкой текста (truncate) и сложными flex-переносами. Легенды реализованы через `break-words` и жесткое позиционирование flex-row, чтобы скриншоты для PowerPoint получались идеальными.
- **Математика KPI:** Выручка Тотал = Выручка Китай + Выручка LADA. Разделение зашито в расчетные функции.
- **Модульная JS-структура:** Все изменения логики вносить строго в соответствующие файлы `site/js/*.js`, не превращая `index.html` обратно в монолит.
- **Синхронизация root и site/:** При изменении файлов в `site/` дублировать их в корень проекта (`index.html`, `js/`, `css/`) для локальной совместимости.
- **Не затирать Master ID Matcher:** Файлы `partner_matcher.html`, `partners_registry.json`, `russia_dealer_benchmarks.json` являются критически важными компонентами проекта.
