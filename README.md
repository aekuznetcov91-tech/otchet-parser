
## 3. КЛЮЧЕВЫЕ ОБНОВЛЕНИЯ И ИСПРАВЛЕНИЯ (СЕНТЯБРЬ 2026)

### А) Капитальный аудит и исправление Master Partner Registry:
1. **Разделение «РОЛЬФ» и «ТЦ Кунцево»:**
   - *Проблема:* Из-за пересекающегося вхождения подстрок дилерских центров («Рольф Кунцево») сделки независимого холдинга **ТЦ Кунцево** ошибочно привязывались к холдингу **РОЛЬФ**.
   - *Решение:* Логика сопоставления в `scripts/parser_engine.py` и правила `partners_registry.json` полностью изолированы. ТЦ Кунцево выделен в самостоятельный Master ID (`id: kuntsevo`).
   - *Фактические показатели:*
     - **ТЦ Кунцево:** 133 сделки, абсолютный лидер по продажам Geely и Belgee.
     - **РОЛЬФ:** 180 сделок (многобрендовый портфель).
2. **Разделение «Прагматика» и «Атик-Моторс»:**
   - Изолированы дилерские центры холдинга «Прагматика» (13 сделок) от независимого партнера «Атик-Моторс» (8 сделок).
3. **Разграничение «Вагнер» и «Авторитейл М»:**
   - Исправлена привязка юрлиц в Северо-Западном регионе.
4. **Консолидация холдинга «АГАТ»:**
   - Объединены 13 дочерних юридических лиц группы компаний «АГАТ» (211 сделок суммарно) под единый Master ID с сохранением филиальной аналитики.
5. **Синхронизация реестров:**
   - Все 3 файла реестра (`data/partners_registry.json`, `partners_registry.json`, `site/partners_registry.json`) приведены к полной идентичности.

### Б) Банковская аналитика и каналы продаж:
- В `scripts/parser_engine.py` и `site/js/data-loader.js` интегрирован модуль анализа кредитных программ:
  - **Автокредит СберАвто / Сбербанк:** расчет доли проникновения автокредитования (TR%), сплит комиссионных доходов.
  - **Сторонние банки:** учет кредитных договоров банков-партнеров (ВТБ, Совкомбанк, Альфа, Росбанк).
  - **Собственные средства:** анализ сделок за наличный / безналичный расчет.
- **Чип-фильтры каналов на дашборде:**
  - `Все`: полный объём сделок (B2C розница + Опт МП2 + ФДЦ).
  - `Без МП2`: операционная розница (B2C + ФДЦ) без учета дилерского опта.
  - `Розница B2C`: только прямые розничные выдачи клиентам через сеть ДЦ.

### В) Сквозная воронка и гео-аналитика лидов:
- **6-этапная воронка PostHog (`site/js/funnel.js`):** Витрина (`Listing` ➔ `Card Show` ➔ `Card Click` ➔ `Offer` ➔ `Click Send` ➔ `Success`) ➔ CRM-квалификация ➔ ДЦ vs ФДЦ.
- **Drilldown в карточки BFS (`site/js/lead-geo.js`):** Клик по любому показателю открывает список клиентов с прямой ссылкой вида `https://backoffice.x.sberauto.com/crm/manager/{client_id}`.

## 4. ИНСТРУКЦИЯ ДЛЯ РАЗРАБОТЧИКА (БЫСТРЫЙ СТАРТ)

### 1. Получение последних изменений из Git:
```bash
git checkout main
git pull origin main
```

### 2. Запуск локального дашборда для тестирования:
```bash
python3 -m http.server 8080 -d site
```
После запуска открыть в браузере: `http://localhost:8080/index.html`.

### 3. Обновление данных (ETL):
При поступлении свежих выгрузок сделок (`DEAL_YYYYMMDD_...`) или лидов (`data (X)...`):
1. Поместить файлы в корневую директорию проекта.
2. Запустить ETL-парсер:
   ```bash
   python3 scripts/parser_engine.py
   ```
3. Скрипт автоматически найдет свежие файлы, проведет дедупликацию, пересчитает выручку без НДС, сопоставит партнеров по Master ID и обновит `data.json` и `site/data.json`.

### 4. Запуск автоматических тестов:
Перед любым коммитом или деплоем обязательно прогнать тесты:
```bash
python3 -m unittest discover tests
```
Все 21 тест должны завершаться со статусом `OK`.

### 5. Деплой на Cloudflare Pages:
Для отправки изменений на боевой сервер выполните:
```bash
python3 deploy_to_cloudflare.py
```
Скрипт выполнит сборку, валидацию файлов, деплой на Cloudflare Pages и автоматический `git push` в репозиторий GitHub.

## 5. ПРАВИЛА РАБОТЫ И ИНВАРИАНТЫ КОДОВОЙ БАЗЫ

1. **🚨 Синхронизация Git и Cloudflare:**
   - Всё, что деплоится на Cloudflare Pages, **ОБЯЗАТЕЛЬНО** коммитится и пушится в Git (`origin main`). Никаких рассинхронов между локальной разработкой и репозиторием.
2. **Модульность JavaScript:**
   - Запрещено переносить логику обратно в `site/index.html`. Все доработки вносятся строго в модули `site/js/*.js` (`charts.js`, `tables.js`, `debtors.js`, `funnel.js`, `lead-geo.js`, `kam-dashboard.js`, `utils.js`).
3. **Master Partner Registry:**
   - Редактирование привязок дилеров осуществляется через `data/partners_registry.json`. При изменениях обязательно запускать `python3 scripts/parser_engine.py` для обновления боевых файлов.
4. **Формат ссылок BFS:**
   - Прямой адрес на карточку клиента в CRM Backoffice строго формируется по шаблону:
     `https://backoffice.x.sberauto.com/crm/manager/{client_id}`
5. **Финансовая модель:**
   - Комиссия СберАвто = 2% от суммы ДКП.
   - Выручка без НДС = `Комиссия / 1.22`.
   - Опт МП2 (Wholesale, холд 1 000 ₽) **СТРОГО ИСКЛЮЧЕН** из розничной воронки конверсий.
