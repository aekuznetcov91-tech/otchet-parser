## 📊 Основные разделы дашборда:

1. **Диаграмма:** KPI-карточки (Сделки, Авансы, Средний чек, ARPU, Выручка без НДС), сплит по брендам (Китай / LADA), динамика по дням и типам B2C.
2. **Динамика:** Подробная подневная и недельная разбивка ключевых метрик.
3. **Динамика месяцы:** Сравнение помесячной динамики (Август 2026 vs Июль 2026).
4. **Партнеры:** Сводная матрица по дилерским холдингам, КАМам и типам операций (Лиды, Предоплаты, Сделки).
5. **Менеджеры:** Рейтинг менеджеров и старших менеджеров по количеству выдач и выручке.
6. **🎯 Воронка брендов (Новое!):**
   * Сквозная конверсионная матрица по 6 брендам: **JETOUR**, **LADA**, **TENET (Chery)**, **CHANGAN**, **GAC**, **SOLARIS**.
   * Клиентский путь: *Лиды CRM ➔ Квалификация (`Целевой == 1`) ➔ Расчеты кредита ➔ Офферы клиентам ➔ Ветка ДЦ vs Ветка ФДЦ ➔ Сделки (без МП2) ➔ Выручка*.
   * Интерактивные круговые диаграммы сплита лидов и сплита выручки.
7. **В ожидании:** Автомобили и клиенты в статусе ожидания выдачи (по брендам и менеджерам).

## 📂 Как обновлять данные (2 способа):

### Способ 1. Локально на компьютере (в 1 клик):
1. Положите свежие выгрузки в папку `raw_data/`:
   * Сделки (Excel / CSV / XLS / XLSM);
   * Лиды (Excel);
   * Справочник партнеров (Excel);
   * Скриншот воронки (`funnel.jpg`) или `funnel_metrics.json`.
2. Запустите файл **`Выгрузить_на_Сайт.bat`**.  
   *Парсер пересчитает все данные за 3 секунды и сразу выгрузит обновленный сайт на Cloudflare!*

### Способ 2. Через GitHub (в браузере):
1. Откройте папку **[raw_data/](https://github.com/beckelaguas723-gif/otchet-parser/tree/main/raw_data)**.
2. Нажмите **Add file ➔ Upload files** и перетащите файлы.
3. Нажмите **Commit changes** — сайт обновится автоматически через GitHub Actions.
