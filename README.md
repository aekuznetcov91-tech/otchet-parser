## 📊 Основные разделы дашборда:

1. **Диаграмма:**
   - **5 Top KPI:** Сделки, Авансы, Средний чек (сплит Китай / LADA), ARPU (без НДС), Выручка (без НДС).
   - **План vs Факт Q3 2026:** Интерактивные прогресс-бары к целям квартала (5 000 авто, 170 млн ₽ выручки, TR% 1.9%) со счетчиком оставшихся дней и темпом сделок.
   - **Сплит брендов и типов B2C:** Pie-чарты с HTML-легендами и кнопками копирования в буфер обмена как PNG для презентаций.
   - **Динамика продаж по дням:** Линейные графики с подсветкой выходных дней.
   - **🗺️ Heatmap регионов РФ:** Топ-20 субъектов РФ по продажам с распределением долей и количеством активных ДЦ.
2. **Динамика:** Подробная подневная и недельная разбивка ключевых метрик по брендам и типам B2C.
3. **Динамика месяцы:** Сравнение помесячной динамики и понедельный тренд ARPU и среднего чека.
4. **Партнеры (Master Partners):**
   - `ID`: Сквозной цифровой идентификатор партнера.
   - `Лиды (BI)`: число входящих лидов из BI.
   - `Предоплаты`: количество внесенных авансов.
   - `Сделки с лидов`: закрытые сделки, пришедшие с лидов без предоплаты (`not has_prepay`).
   - `Сделки с МП`: закрытые сделки по каналам `МП1`, `МП2`, `МП3` (маркетплейсы).
   - `Сделки Тотал`: итоговое число закрытых сделок.
   - `Конверсия (Сделка/Лид) %`: сквозная конверсия.
   - `Править ➔`: переход к редактированию партнера в онлайн-хабе `partner_matcher.html`.
5. **Менеджеры:** Иерархический рейтинг менеджеров по группам старших менеджеров.
6. **🎯 Воронка брендов (Сквозная аналитика 13 брендов):**
   - **Автогенерация периодов:** Динамические кнопки месяцев (`2026-08`, `2026-07` и будущие) и брендов из `data.json`.
   - **Интеграция Витрины СберАвто (PostHog):** 6 шагов кликстрима (*Листинг ➔ Карточка авто ➔ Клик ➔ Экран оффера ➔ Клик отправки ➔ Экран успеха*).
   - **Сквозной путь CRM:** *Лиды CRM ➔ Квалификация (`Целевой == 1`) ➔ Расчеты кредита ➔ Развилка (ДЦ vs ФДЦ) ➔ Сделки розницы (без МП2) ➔ Выручка розницы*.
7. **В ожидании (Должники ДКП):**
   - Контроль незакрытых сделок по компаниям.
   - **Двойной экспорт:**
     - `[ 📊 Выгрузить таблицей ]`: единый Excel-файл со всеми выбранными должниками (`Компания`, `Дата аванса`, `Марка`, `ВИН`).
     - `[ По компаниям ]`: формирование отдельных файлов Excel по каждому выбранному холдингу.

## 🗺️ Онлайн-хаб географии брендов (`partner_matcher.html`):
* **Интерактивный Охват Брендов:** отношение городов присутствия марки в РФ (Рынок) к подключенным городам в СберАвто ➔ точный потенциал расширения партнерской сети.
* **Дилеры ОЕМ (642 крыши по 15 брендам в 102 городах):** реестр официальных дилеров с быстрым копированием списка городов в алфавитном порядке.
* **Очередь несметченных:** авто-сопоставление названий из Битрикс и BI.
* **Реестр Master Partners:** редактирование цифровых ID, КАМов, холдингов и алиасов с синхронизацией в облако.

## 🏗️ Архитектура (7 модулей JS):
- `site/js/utils.js` — форматтеры, константы Q3, буфер обмена, Toast-уведомления (без `alert()`).
- `site/js/data-loader.js` — загрузка `data.json`, динамический фильтр дат, План vs Факт Q3.
- `site/js/charts.js` — Chart.js визуализация, pie/line графики.
- `site/js/tables.js` — рендеринг таблиц с умным поиском (`<datalist>`) и сортировкой колонок.
- `site/js/debtors.js` — должники ДКП и экспорт Excel.
- `site/js/funnel.js` — сквозная воронка 13 брендов.
- `site/js/heatmap.js` — региональная аналитика РФ.
- `site/css/dashboard.css` — стили, анимации бликов (shimmer glare) и зума кнопок.

## 🧪 QA-тестирование и надежность

Проект оснащен автоматизированным тестовым набором [`tests/test_brand_funnel.py`](tests/test_brand_funnel.py) (10/10 тестов):
* `test_01_data_json_structure`: Проверка структуры и наличия ключевых узлов JSON.
* `test_02_sys_db_sales_and_revenue`: Проверка объема сделок (>1 000) и выручки (>35M ₽).
* `test_03_brand_funnel_months`: Валидация срезов по месяцам.
* `test_04_brand_funnel_math_consistency`: Математическая сходимость $(Сделки_{розница} + Сделки_{МП2} = Сделки_{тотал})$ и расчет ARPU.
* `test_05_vitrina_ocr_data`: Проверка данных витрины PostHog из скриншотов.
* `test_06_index_html_ui_components`: Валидация селекторов месяцев и DOM-элементов.
* `test_07_debtors_and_export_modal`: Проверка модального экспорта должников.
* `test_08_no_duplicate_processing`: Проверка хэш-дедупликации парсера.
* `test_09_all_13_brands_presence`: Наличие всех 13 брендов в воронке.
* `test_10_javascript_syntax_integrity`: Проверка синтаксиса всех JS-модулей через движок WebKit JavaScriptCore (JXA).

Запуск тестов:
```bash
python3 tests/test_brand_funnel.py
```
