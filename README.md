## 📊 Основные разделы дашборда:

1. **Диаграмма:** KPI-карточки (Сделки, Авансы, Средний чек, ARPU, Выручка без НДС), сплит по брендам (Китай / LADA), динамика по дням и типам B2C.
2. **Динамика:** Подробная подневная и недельная разбивка ключевых метрик.
3. **Динамика месяцы:** Сравнение помесячной динамики (Август 2026 vs Июль 2026).
4. **Партнеры:** Сводная матрица по дилерским холдингам, КАМам и типам операций (Лиды, Предоплаты, Сделки).
5. **Менеджеры:** Рейтинг менеджеров и старших менеджеров по количеству выдач и выручке.
6. **🎯 Воронка брендов (Сквозная многомесячная аналитика):**
   * **Выбор периода:** Переключение в 1 клик между **Августом 2026**, **Июлем 2026** и **Всеми периодами (Тотал)**.
   * **Охват 13 брендов:** `JETOUR`, `LADA`, `TENET`, `CHANGAN`, `GAC`, `SOLARIS`, `SOUEAST`, `BELGEE`, `GEELY`, `HAVAL`, `JAECOO`, `OMODA`, `МОСКВИЧ`.
   * **Интеграция Витрины СберАвто (PostHog):** 6 шагов кликстрима (*Листинг ➔ Карточка авто ➔ Клик ➔ Шаги ➔ Отправка ➔ Экран успеха*).
   * **Сквозной путь CRM:** *Лиды CRM ➔ Квалификация (`Целевой == 1`) ➔ Расчеты кредита ➔ Офферы клиентам ➔ Развилка (ДЦ vs ФДЦ) ➔ Сделки розницы (без МП2) ➔ Выручка*.
   * **Интерактивные диаграммы:** Сплит лидов и розничной выручки по брендам за выбранный период.
7. **В ожидании:** Автомобили и клиенты в статусе ожидания выдачи (по брендам и менеджерам).

## 🧪 QA-тестирование и надежность

Проект оснащен автоматизированным тестовым набором [`tests/test_brand_funnel.py`](tests/test_brand_funnel.py):
* `test_01_data_json_structure`: Проверка структуры и наличия ключевых узлов JSON.
* `test_02_sys_db_sales_and_revenue`: Проверка объема сделок (>1 000) и выручки (>35M ₽).
* `test_03_brand_funnel_months`: Валидация срезов по месяцам (`2026-08`, `2026-07`, `all`).
* `test_04_brand_funnel_math_consistency`: Математическая сходимость $(Сделки_{розница} + Сделки_{МП2} = Сделки_{тотал})$ и расчет ARPU.
* `test_05_vitrina_ocr_data`: Проверка данных витрины PostHog из скриншотов.
* `test_06_index_html_ui_components`: Валидация селекторов месяцев и DOM-элементов.
* **WebKit JavaScriptCore:** Синтаксическая валидация всех JS-скриптов движком браузера.

Запуск тестов:
```bash
python3 tests/test_brand_funnel.py
```

## 📂 Как обновлять данные (2 способа):

### Способ 1. Локально на компьютере (в 1 клик):
1. Положите свежие выгрузки в папку `raw_data/`:
   * Сделки (Excel / CSV / XLS / XLSM);
   * Лиды (Excel);
   * Справочник партнеров (Excel);
   * Скриншоты воронки витрины или `brand_funnels_clean.json`.
2. Запустите файл **`Выгрузить_на_Сайт.bat`**.  
   *Парсер пересчитает все данные за несколько секунд и сразу выгрузит обновленный сайт на Cloudflare!*

### Способ 2. Через GitHub (в браузере):
1. Откройте папку **[raw_data/](https://github.com/beckelaguas723-gif/otchet-parser/tree/main/raw_data)**.
2. Нажмите **Add file ➔ Upload files** и перетащите файлы.
3. Нажмите **Commit changes** — сайт обновится автоматически через GitHub Actions.
